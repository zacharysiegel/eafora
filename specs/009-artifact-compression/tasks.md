# Tasks: artifact compression

**Feature**: 009-artifact-compression | **Branch**: `artifact-compression` | **Date**: 2026-08-26

**Input**: [spec.md](spec.md), [plan.md](plan.md)

One PR, for the reason recorded in plan.md §Phasing: the producer half alone publishes artifacts no deployed client can read and breaks the site build, and the consumer half alone cannot read anything published, so neither is independently mergeable in a state that runs. Test-first throughout for the pure functions, per Constitution Principle VII. Every numbered task is one commit unless it says otherwise.

The build-script tasks are not cleanup at the end. `scripts/build/verify-site-tree.sh` fails as written the moment an embedded shard is compressed, so T019 through T022 are the gate that lets the tree be built at all, and they are ordered before the end-to-end run that needs them.

Read `docs/conventions/logging.md` before writing the log lines, `docs/conventions/types.md` before naming anything, and `docs/conventions/conditional-compilation.md` before touching a dependency table.
